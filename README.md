# coopid · Landing de brookies

Recreación en HTML + CSS de la landing page de **coopid** — *"El flechazo entre el
brownie y la cookie."* Brookies artesanales, horneados con amor.

Proyecto de UX/UI. Página estática de una sola vista, fiel al diseño, la paleta y los
textos del mockup original.

## Vista rápida

```bash
# desde la carpeta del proyecto
python3 -m http.server 8777
# abrí http://localhost:8777
```

O simplemente abrí `index.html` en el navegador.

## Estructura

```
index.html          Marcado de todas las secciones
styles.css          Estilos y responsive
assets/
  fonts/            Choco Taste (script del logo y acentos)
  img/              Cupido, brookie central y fotos de sabores
```

## Marca

| Rol | Valor |
| --- | --- |
| Rojo Coopid (principal) | `#7C1B0C` |
| Beige (fondo) | `#F2E8D5` |
| Crema hueso (fondo) | `#F7F7F5` |
| Tinta (texto) | `#1E140F` |

**Tipografías**

- **Choco Taste** — script de marca (logo y palabras destacadas como *flechazo*).
- **Fredoka** — títulos redondeados.
- **Hanken Grotesque** — cuerpo, etiquetas y navegación.

## Secciones

1. Marquee superior + navegación
2. Hero — *El flechazo entre el brownie y la cookie*
3. Qué es un brookie — 4 características + brookie central
4. Sabores — carrusel de cuatro variedades
5. La marca — historia de coopid
6. Footer — navegación, redes e imagotipo

## Notas

- Las fotos de los sabores usan la imaginería disponible de la marca a modo de
  placeholder (no se contaba con la foto exacta de cada variedad).
- *Choco Taste* está incluida en su versión **Trial** solo para fines de este
  proyecto académico.
